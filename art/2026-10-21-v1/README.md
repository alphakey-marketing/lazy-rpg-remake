## Menu bar 及 icon 建議

主選單／側邊入口現有 emoji 值得優先統一，避免 Android 字形與手繪風格混雜。五分頁維持戰鬥、英雄、訓練、黑貓、商店；選中用金色底、深色文字，通知點避開圖示。

現有 CurIcon／SlotIcon SVG 已符合粗線風格，之後可沿用向量並統一輪廓及配色；箭嘴、叉號、勾號毋須全部換 PNG。資源維持原辨識：金幣金、寶石粉紅、精煉石藍、碎片紫、護符綠。

03 圖集銀金護符、藍色戒指係探索稿；正式接圖優先用 05 圖集綠色護符、粉紅戒指。額外藍鑽只係商店視覺候選，唔代表新增貨幣。靴係候選，唔代表新增裝備欄。史萊姆王係首章 Boss 美術候選，未更改現有怪物設定。
